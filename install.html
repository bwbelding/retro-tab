Install Retro

Two ribbon tabs for PowerPoint for Mac: Retro Build and Retro Polish. No admin rights and no Terminal needed.

1. Download both files

Download Retro Build Download Retro Polish

They land in your Downloads folder as retro-build.xml and retro-polish.xml.

2. Copy them into PowerPoint's add-in folder

  1. Quit PowerPoint.
  2. In Finder, press ⌘⇧G (Go to Folder) and paste:
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef
  3. If Finder says the folder doesn't exist, go to ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents instead and create a folder named wef there.
  4. Drag both .xml files from Downloads into the wef folder.

3. Open PowerPoint

  1. Open any presentation.
  2. Look for the Retro Build and Retro Polish tabs on the ribbon. If they aren't there, go to Home → Add-ins (or Insert → Add-ins → My Add-ins) and pick Retro Build, then Retro Polish.
  3. On the Retro Build tab, click My Library. In the pane that opens, click More (the last item in its top bar).
  4. On the Retro Polish tab, click Diagnostics. Opening it from both tabs lets Retro confirm the two tabs share saved data.
  5. Click Test folder picking and choose any folder with a few photos.
  6. Click Copy report and paste it into our chat.

If something goes wrong

No Retro tabs and no Retro in the Add-ins list: your company may block add-ins you install yourself. Tell me; the fallbacks are asking IT to deploy these same two files, or PowerPoint on the web.

Tabs appear but a pane says it can't load: your network may block this site. Diagnostics or a screenshot tells us which.

Some PowerPoint buttons are missing from a Retro tab: note which ones; PowerPoint for Mac may not offer every built-in button to add-ins.

To update Retro: nothing to do. PowerPoint loads the latest version each time; restart PowerPoint to pick up changes.
